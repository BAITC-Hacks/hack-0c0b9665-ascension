# Анимации рабочего интерфейса

Изолированный слой движения для существующего интерфейса, база `56c5150`.
Файлы: `public/motion.css`, `public/motion.js`. Внешних зависимостей нет.

## Подключение

Владелец главного UI подключает CSS **после** визуальных стилей и модуль рядом с `app.js`:

```html
<link rel="stylesheet" href="/motion.css">
<script type="module" src="/motion.js"></script>
```

Модуль запускается автоматически после готовности DOM. Достаточно подключить его один раз.
Он не импортирует приложение, не отправляет запросы, не читает детали расчётных событий,
не меняет текст, значения, `hidden`, ARIA-атрибуты или фокус и не управляет картой.

## Поведение

- Hero, четыре метрики и заголовки секций появляются один раз при попадании в экран:
  450 мс, смещение 6 px, шаг 40 мс, задержка максимум 120 мс.
- Новые выбранные меры, смена района, результаты и слоты сравнения появляются за 280 мс.
  Повторная перерисовка во время проверки совместимости не запускает заново уже показанные карточки.
- Бюджет и количество решений сразу содержат окончательные значения. Короткая смена
  прозрачности за 240 мс подтверждает изменение; промежуточных чисел и count-up нет.
- Наведение и нажатие кнопок, фильтров и доступных карточек используют 160/80 мс.
  Наведение со смещением включается только для точного указателя с поддержкой hover.
- Анимируются `transform`/`opacity`; CSS также сглаживает уже существующие цвета состояний.
  Существующая анимация `width` полосы бюджета отключена: её шириной продолжает владеть приложение.
  Нет постоянного `will-change`, бесконечных декоративных эффектов или обработчиков прокрутки.

## События и наблюдение

В базе `app.js` и `map.js` отправляют `scenario:calculated` и `city:changed` в `window`.
Модуль также слушает `scenario:invalidated` и поддерживает отправку этих событий в `document`.
Одинаковая работа от всплывающего события объединяется в одном кадре. Отсутствующее в базе
событие сброса компенсируется наблюдением за `hidden` и дочерними узлами панели результата.

Один `MutationObserver` наблюдает только именованные UI-контейнеры. Для секций проверяется
только атрибут `hidden`; для списков — непосредственные дочерние узлы. `subtree: true`
используется только на четырёх небольших текстовых значениях бюджета/счётчика.
`body`, поддерево `#app`, `#city-map` и MapLibre DOM не наблюдаются.
Изменения объединяются через `requestAnimationFrame`; сама анимация не пишет DOM и не
вызывает рекурсивные callbacks. Удалённые карточки снимаются с `IntersectionObserver`,
в том числе когда их заменили до первого попадания в экран.

## Доступность и отказоустойчивость

- Исходные CSS/DOM видимы. Нет класса, который сначала скрывает интерфейс до загрузки JS.
  Web Animations API использует конечные эффекты без постоянного конечного состояния.
- При отсутствующем `motion.js` или неподдерживаемом API интерфейс продолжает работать.
- Любой `hidden`/`inert` на элементе или предке запрещает анимацию; модельные панели других
  городов остаются скрытыми. Ни одно правило motion не задаёт `display` или `visibility`.
- При `prefers-reduced-motion: reduce` новые эффекты не запускаются. Изменение настройки
  сразу отменяет активные эффекты; CSS отключает переходы и смещения кнопок.
- `focusin` сразу отменяет движение элемента с фокусом и его анимированных предков.
  Фокус, outline и клавиатурная навигация не задерживаются.
- Печать, скрытие вкладки и уход со страницы отменяют активные эффекты.

Явные вызовы `scrollIntoView({ behavior: 'smooth' })` в `app.js` принадлежат владельцу UI:
для reduced-motion они должны выбирать `instant`. CSS не может отменить явный параметр JS.
Переходы камеры карты остаются ответственностью `map.js`.

## Проверка 23 сентября 2026

Проверялся собственный checkout `feat/h12-interface-motion` в локальном браузере Chromium.
Временный HTTP preview подключал два новых файла к существующему `index.html` без его изменения.
Маршруты `/api/simulate` и `/api/explain` в preview были заблокированы; расчёт и AI не запускались.

| Проверка | Результат |
| --- | --- |
| `node --check public/motion.js` | Успешно |
| Начальный экран 1280 px | Hero и четыре метрики: 450 мс, шаг 40 мс; после завершения нет активных эффектов |
| Загрузка демо | Пять выбранных мер, бюджет сразу 5; результат остаётся скрытым |
| Алматы → Астана | Все `.model-only` скрыты в Алматы; после возврата сохраняются пять мер и бюджет 5 |
| 390 × 844 px | Ширина документа 375 px при viewport 390 px, без горизонтального переполнения страницы |
| 12 замен результата вне экрана | 12 снятий с IntersectionObserver, отсоединённых наблюдаемых узлов: 0 |
| Фокус во время появления тестовой карточки | До фокуса 1 эффект, сразу после 0; opacity 1, фокус на кнопке |
| Reduced-motion: загрузка и выбор демо | Вызовов WAAPI: 0, активных эффектов: 0; transition 0s, transform none |
| Без подключения `motion.js` | Интерфейс видим, выбор демо работает, пять мер/бюджет 5, расчётная кнопка доступна |

Появление результатов и фокус проверялись временным DOM-примером с текстом «Motion QA»
и событием в `document`, без вызова расчётного ядра. После проверки страница перезагружена.
Проверка с объединёнными визуальными стилями, графикой и обновлённым `app.js` остаётся
за интегратором; эти три файла не содержат изменений чужих зон.
