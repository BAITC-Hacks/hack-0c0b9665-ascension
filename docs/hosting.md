# Публикация городской карты

Проверено по официальным источникам 23 сентября 2026 года. Основной исходный код остаётся в репозитории `BAITC-Hacks/hack-0c0b9665-ascension`.

## Варианты бесплатного хостинга

| Сервис | Подходит текущему приложению | Существенные условия |
| --- | --- | --- |
| Render Free | Прямой запуск Node.js 24, HTML, карты и HTTP API одним сервисом | Засыпает после 15 минут без запросов; следующий запуск занимает примерно минуту. 750 бесплатных часов на workspace в месяц. Локальные записи теряются при перезапуске. Для приватного репозитория нужен доступ GitHub App. |
| Cloudflare Workers Free | Карта со статическими файлами и API; нужен адаптер серверных маршрутов | 100 000 динамических запросов в сутки, 10 мс CPU на запрос. Ожидание внешнего API не является CPU, но перебор сценариев выполняется на CPU. Требуется проверка расчёта и объяснения в Workers. |
| Vercel Hobby | Нужен адаптер HTTP API под Functions | Только личное некоммерческое использование. Нет совместной работы с приватным репозиторием; коммит должен принадлежать владельцу Hobby team. Максимальное выполнение Functions — 300 секунд. Для будущего рабочего инструмента акимата это менее подходящий бесплатный вариант. |

Источники: [Render Free](https://render.com/docs/free), [Render Git provider](https://render.com/docs/git-provider), [Workers limits](https://developers.cloudflare.com/workers/platform/limits/), [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Vercel private repository collaboration](https://vercel.com/docs/deployments/troubleshoot-project-collaboration).

## Cloudflare: основной вариант публикации

Подготовлены `wrangler.jsonc` и `src/worker.js`. Адаптер использует то же ядро `src/core/simulator.js` и те же данные; отдельной формулы для облака нет. Статика раздаётся через Assets, запросы `/api/*` — через Worker. Заголовки статики заданы в `public/_headers`.

Из корня конкурсного репозитория:

```powershell
npx --yes wrangler@4.136.3 login
npx --yes wrangler@4.136.3 deploy --dry-run
npx --yes wrangler@4.136.3 deploy
```

Для публикации только через CLI достаточно аккаунта Cloudflare; установки приложения в GitHub-организацию не требуется. Исходный репозиторий остаётся тем же. CLI выдаёт HTTPS-адрес `workers.dev` после успешной публикации. Команда `deploy` является публикацией; `--dry-run` только проверяет сборку.

Ключ добавляется после публикации через секреты Cloudflare Dashboard либо интерактивно командой `npx --yes wrangler@4.136.3 secret put OPENAI_API_KEY`. Значение вводится в защищённый запрос CLI, не в аргумент команды и не в конфигурацию. `OPENAI_MODEL` можно задать переменной окружения. Наличие локального `.env.local` не означает, что его секреты уже загружены в Cloudflare.

В облачном пояснении отключён перебор замен одного решения, чтобы укладываться в небольшой CPU-бюджет. UI получает честный текст, что такой поиск не выполнялся. Сам расчёт пяти решений и Score остаётся прежним.

Платные обращения к модели ограничены общим постоянным счётчиком `AIBudget`: 100 отправок за всё время, 10 за минуту и 2 одновременно для всех посетителей. Счётчик хранится в SQLite Durable Object `global`, сохраняется после перезапуска и учитывает разрешение до обращения к провайдеру. Ошибки провайдера тоже расходуют разрешение; автоматического сброса 100 запросов нет. Освобождение разрешения снимает только ограничение одновременности. Если запрос оборвался, резерв одновременности истечёт через 65 секунд.

Локальный счётчик Worker и платформенный Rate Limiting дают дополнительные ограничения до обращения к постоянному хранилищу. Отсутствие или ошибка любого обязательного хранилища ограничений блокирует запрос к модели и возвращает расчётное пояснение. 100 запросов — ограничение количества, а не точная сумма в долларах: стоимость зависит от модели и токенов. [Rate Limiting](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/), [Durable Objects Free с SQLite](https://developers.cloudflare.com/durable-objects/platform/pricing/).

Локальная проверка: `node --test tests/worker.test.js` проверяет официальный результат (стоимость 95, Score 56.54307), обработку ошибочного JSON и тела свыше 32 KiB, методы HTTP, приватность ключа и конкурентный лимит. `npx --yes wrangler@4.136.3 dev --local --port 8799` запускает тот же адаптер в локальном runtime. Перед сдачей публичный адрес проверяется отдельно: HTML, карта, поиск города, расчёт и объяснение.

## Render: готовая конфигурация

В корне находится `render.yaml`. Он запускает сервер без изменения ядра расчёта: Node.js 24, `HOST=0.0.0.0`, порт из окружения платформы, `/api/health` для проверки. Автоматическая публикация каждого коммита выключена, чтобы публиковать проверенную сборку вручную. Формат проверен по [Blueprint specification](https://render.com/docs/blueprint-spec) и [Node version](https://render.com/docs/node-version).

1. Войти в [Render Dashboard](https://dashboard.render.com/).
2. Подключить GitHub и разрешить Render доступ только к выданному репозиторию. Если организация требует одобрения установки, его должен выдать её администратор; изменение видимости репозитория не требуется.
3. Выбрать **New → Blueprint**, указать репозиторий и ветку с проверенными изменениями. Перед созданием проверить `Free` и отсутствие платных ресурсов.
4. Развернуть Blueprint. Альтернатива — **New → Web Service**: Node, build `npm test`, start `npm start`, `NODE_VERSION=24`, `HOST=0.0.0.0`, health `/api/health`, план Free.
5. При наличии ключа добавить `OPENAI_API_KEY` только в серверное хранилище Environment. `OPENAI_MODEL` задать доступной в проекте моделью. Без ключа работает расчётное пояснение.
6. Открыть выданный HTTPS-адрес, проверить карту, выбор города, расчёт пяти решений и `/api/health`. Значение `aiConfigured:true` подтверждает наличие ключа, но успешный запрос к модели проверяется отдельным вызовом объяснения.

Бесплатный тариф пригоден для демонстрации. Render прямо не рекомендует Free для production. При превышении включённого трафика или build minutes сервис может быть остановлен либо выставлен счёт, если добавлен способ оплаты: [Render FAQ](https://render.com/docs/faq). Для постоянной работы акимата требуются эксплуатационный план, реальные проверенные городские данные и устойчивое хранилище.

## Секреты и данные

Ключ не помещается в браузер, `public/`, Git или ссылку на сайт. Бюджет API относится к серверным обращениям к модели; он не оплачивает хостинг автоматически. Доступность карты и детерминированного калькулятора должна проверяться без ключа.

Географическая подложка не превращает синтетическую модель хакатона в официальные показатели выбранного города. В интерфейсе и демонстрации нужно сохранять это различие.
