# Организаторам: открыть и запустить Ascension

**Готовый сайт:** https://ascension-city-map.azamatbreach.workers.dev — открывается без установки и аккаунта команды.

## На своём компьютере

1. Скачайте ZIP исходников из выданного репозитория и полностью распакуйте его. Либо клонируйте [репозиторий](https://github.com/BAITC-Hacks/hack-0c0b9665-ascension).
2. Установите [Node.js 24 или новее](https://nodejs.org/). Внешние npm-пакеты для запуска не нужны.
3. На **Windows** дважды щёлкните `START-WINDOWS.cmd`. На **macOS/Linux** выполните `sh start-local.sh` из папки проекта.
4. Браузер откроет сайт; адрес также напечатан в терминале. Оставьте окно терминала открытым. Остановка — **Ctrl+C**.

Из любого терминала можно выполнить `node scripts/start-local.js --no-open`, если автоматическое открытие браузера не нужно. Прежний `npm start` также работает.

Стандартный адрес — `http://127.0.0.1:3000`. Если порт занят, остановите предыдущую копию либо добавьте `PORT=3100` в `.env.local` и повторите запуск. Не заменяйте существующий файл настроек. Этот быстрый запуск слушает только локальный компьютер.

| Что проверить | Адрес |
| --- | --- |
| Главная страница | `/` |
| Симулятор, пять мер и сравнение | `/classic.html` |
| Создание обращения жителя | `/citizens.html` |
| Панель акима | `/mayor.html` |
| Состояние сервера | `/api/health` |

В чистой локальной конфигурации панель акима доступна с этого компьютера. Если уже задан `ADMIN_TOKEN`, введите его в панели. Принятые обращения сохраняются в `var/complaints.json`; не удаляйте `var/` при обновлении. Общий реестр команды — отдельная необязательная настройка, описанная в [инструкции](self-hosting.md).

Расчёты по данным кейса, веб-обращения и расчётные пояснения работают без ключей и подписок. Для географической подложки и поиска нужен интернет. AI-пояснение использует **OpenAI Responses API**, модель по умолчанию **`gpt-6-astra`**; NVIDIA-модель и собственное обучение в проекте не используются. Для своего живого AI задайте собственный `OPENAI_API_KEY` в `.env.local`. При отсутствии ключа или ошибке провайдера приложение явно показывает расчётное пояснение. `aiConfigured: true` означает наличие ключа, а успешный вызов модели проверяется отдельно.

## На сервере организаторов

Готовы **Docker Compose**, **systemd** и **Caddy**. Полные команды, настройка собственного домена/HTTPS, постоянного хранилища, AI и Telegram: [развёртывание на своём сервере](self-hosting.md).

Для Docker установите Docker Engine/Desktop с Compose. Скопируйте `.env.example` в `.env.local`, если такого файла ещё нет, и задайте собственный случайный `ADMIN_TOKEN`. Затем:

```sh
docker compose --env-file .env.local up -d --build
docker compose --env-file .env.local ps
```

Откройте `http://127.0.0.1:3000`. Для доступа через домен следуйте разделу Caddy в полной инструкции: Compose по умолчанию публикует порт только на loopback хоста. Данные остаются в постоянном volume после перезапуска. `docker compose down` останавливает сервис; **не добавляйте `-v`**, если нужно сохранить обращения.

## Самопроверка без секретов

```sh
node scripts/self-host-smoke.js
```

Команда проверяет отдельный чистый сервер, официальный пример (**бюджет 95, Score 56.54307**), расчётное пояснение, обращение, защищённую панель и сохранность обращения после перезапуска. Ожидаемый результат — `"ok": true`. Рабочие ключи и обращения не используются. Проверка не подтверждает доступность внешнего AI, Telegram, Docker daemon или настройки HTTPS на другом сервере.
