# Интеграция интерфейса PR #21

История ветки `feat/h12-ui-03-alisher` сохранена merge-коммитом. Итоговая версия использует общий Node/Cloudflare runtime и действующий реестр обращений из PR #36, а основной экран сохраняет новую 3D-карту.

Из PR #21 подключены автономная учебная демонстрация `/demo.html` и объяснение распределения бюджета в `/classic.html`. Демонстрация вызывает действующий API симулятора; её поручение и ответ жителя — явно обозначенные примеры в памяти страницы. Переходы ведут в действующие `/mayor.html` и `/citizens.html`. Объяснение бюджета очищается после изменения сценария и при выходе из модели Астаны.

Иллюстрации и общая библиотека сценариев уже присутствовали в основной ветке. Их новые версии сохранены.

Отдельные кабинеты `/desk.html`, `/akim.html`, `/resident.html`, `/results.html` и Node SQLite-модуль `src/desk` не подключены. Их отдельная база, сессии, идентификаторы и API не заменяют действующий реестр. Требования к будущему адаптеру описаны в [контракте кабинетов](desk-complaints-contract.md). Остальные дополнительные фильтры и инструменты старого интерфейса остаются в истории ветки; они требуют отдельного согласования с жизненным циклом нового приложения.
