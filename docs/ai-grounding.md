# Граница доверия к объяснению

Числовая сводка AI-панели формируется сервером из результата официального ядра. Модель получает готовые факты, но её `summary`, `strengths`, `risks` содержат только качественную прозу. Цифры и другие Unicode-числа в этих полях отклоняются даже тогда, когда такое число встречается в датасете: допустимый бюджет 100 не делает утверждение «Score 100» верным.

Поле `recommendations` у провайдера содержит только коды из динамического enum. Сервер преобразует их в известные рекомендации. Совет по критическим показателям доступен только при их наличии, проверенная замена — только если сервер действительно её вычислил. Произвольная новая мера, шестое решение, пользовательский ID или свободный текст рекомендации не принимаются. Пустой список допустим: сервер предлагает сравнить сценарии. Публичный контракт остаётся прежним: четыре текстовых поля/списка, `mode`, `available`, `model`.

Нарушение контракта даёт честное расчётное пояснение с `reason: invalid_model_analysis`, `available: false`. Невалидный ответ не кешируется. При отключённом серверном поиске сохраняется явная оговорка; наличие отдельного браузерного подбора альтернатив не выдаётся за серверный поиск в AI-вызове. Любой выбранный план снова проходит `/api/simulate`.

Это **не доказательство истинности всей естественной речи**. Качественная проза может содержать неверные причинные связи, числа словами или непроверенные советы вне поля `recommendations`; сервер не пытается доказать семантику любого русского предложения. Консервативный фильтр отклоняет формулировки о гарантии, подтверждённом прогнозе, глобальном оптимуме и слова с корнем «шест» в начале слова после нормализации пробелов и невидимых форматирующих символов. Он может отклонить и отрицательную фразу с такими словами. Такие ограничения намеренно описаны, а synthetic-предупреждение добавляется сервером всегда. Цифры сверяются по основным карточкам и таблице. Модель не имеет инструментов изменения сценария или назначения реальных поручений.

Проверка использует только подставной транспорт: исходный adversarial-ответ со Score 999; ложный Score 100, совпадающий с законным бюджетом; Unicode-числа; запрещённый текст рекомендации; неизвестные и недоступные коды; пропущенный поиск; пустые рекомендации; точная существующая замена M5/Сарыарка → M3/Нура с результатом 57.20556. Реальный API этими тестами не вызывается. Новый публичный живой ответ должен проверяться владельцем публикации после интеграции, поскольку формат запроса провайдеру изменился.
