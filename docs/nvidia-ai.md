# NVIDIA Nemotron: подключение и проверка

Основной вариант для опубликованного сайта — **NVIDIA Nemotron 3 Super через Cloudflare Workers AI**, модель `@cf/nvidia/nemotron-3-120b-a12b`. Она заранее обучена NVIDIA; команда её не обучала и не дообучала, веса в репозиторий не включены. Вычисления выполняет Cloudflare: свой GPU, ключ NVIDIA и подтверждение телефона в NVIDIA для этого способа не нужны. [Модель и условия её использования](https://developers.cloudflare.com/workers-ai/models/nemotron-3-120b-a12b/).

Модель доступна на Workers Free, в пределах квоты аккаунта; доступность не означает неограниченное число запросов. Это явно указано в [обновлении Cloudflare от 28 июля 2026](https://developers.cloudflare.com/changelog/post/2026-07-28-models-require-workers-paid/). Для локального Node.js ниже описан отдельный необязательный путь через NVIDIA NIM.

Модель помогает в двух существующих разделах сайта:

- **«Оценить мой план»** переводит текст в меры каталога и показывает допущения. Сервер проверяет бюджет, районы, количество мер и несовместимости; только допустимый план получает рассчитанный результат и кнопку применения.
- **«Почему получился такой результат»** объясняет сильные стороны, риски и компромиссы рассчитанного сценария. Модель получает исходные факты, эффекты мер и результаты расчёта; числовую сводку формирует сервер.

Это соответствует роли LLM в приложении «Датасет районов»: объяснять рассчитанные последствия, сравнивать решения и помогать с рекомендациями, не придумывая числа. Score вычисляет общее детерминированное ядро по синтетическим данным кейса. Текст модели не является прогнозом для реального города. Название NVIDIA появляется у результата только после успешного ответа выбранного провайдера; состояние `aiConfigured` в health не доказывает работу модели.

## Опубликованный сайт: Cloudflare Workers AI

Используйте собственный Worker по [инструкции хостинга](hosting.md). В `wrangler.jsonc` добавьте верхнеуровневую привязку `ai` и установите `AI_PROVIDER` внутри существующего `vars`:

```jsonc
"ai": { "binding": "AI" },
"vars": {
  "AI_PROVIDER": "nvidia-cloudflare"
  // Сохраните остальные существующие переменные.
}
```

Это фрагмент для объединения с существующим файлом: сохраните настройки статики, хранилищ, лимитов и своего адреса. Приложение использует фиксированную модель `@cf/nvidia/nemotron-3-120b-a12b`; `NVIDIA_MODEL` относится к отдельному NIM-пути. Привязка `AI` предоставляет серверу доступ к Workers AI в вашем аккаунте, поэтому `NVIDIA_API_KEY` для этого backend не задаётся. [Настройка привязки Workers AI](https://developers.cloudflare.com/workers-ai/configuration/bindings/).

Из корня настроенного проекта выполните `npx wrangler deploy`. Для публикации нужен собственный аккаунт Cloudflare; посетители сайта ключи не вводят. После публикации выполните проверку ниже. Обычный `npm start` не создаёт облачную привязку `AI`: для локального Node.js используйте расчётный режим или NIM.

## Локальный Node.js: необязательный NVIDIA NIM

Прямой NVIDIA NIM использует другую заранее обученную модель — **Nemotron 3.5 Lightning**, `nvidia/nemotron-3.5-lightning-30b-a3b`. Условия модели — OpenMDW 1.1, пробного API — NVIDIA API Trial Terms. [Карточка модели и условия](https://build.nvidia.com/nvidia/nemotron-3.5-lightning-30b-a3b/modelcard).

Получите собственный API-ключ в [NVIDIA API Catalog](https://build.nvidia.com/). В корневой `.env.local` добавьте или измените следующие строки, сохранив остальные настройки:

```dotenv
AI_PROVIDER=nvidia
NVIDIA_API_KEY=
NVIDIA_MODEL=nvidia/nemotron-3.5-lightning-30b-a3b
```

Впишите ключ после `NVIDIA_API_KEY=` только в локальном файле. Затем перезапустите `START-WINDOWS.cmd`, `sh start-local.sh` или `npm start`. Выбор `AI_PROVIDER=nvidia` использует NVIDIA-ключ; оставшийся `OPENAI_API_KEY` не подменяет его. Для возврата к прежнему провайдеру установите `AI_PROVIDER=openai` и настройте свой `OPENAI_API_KEY`.

Без ключа выбранного провайдера расчёты и обращения работают, объяснение явно обозначено как расчётное, а текстовый AI-план не генерируется. Для внешнего AI нужны интернет и доступная квота владельца ключа.

При выборе именно NIM для своего Worker установите в `vars` `AI_PROVIDER=nvidia` и его `NVIDIA_MODEL`, добавьте ключ командой `npx wrangler secret put NVIDIA_API_KEY`, затем выполните `npx wrangler deploy`. `secret put` запрашивает значение в терминале и сразу публикует новую версию существующего Worker. Это альтернативный путь; основной Workers AI-путь выше не требует этого секрета. [Секреты Cloudflare Workers](https://developers.cloudflare.com/workers/configuration/secrets/).

## Проверка настоящего ответа на сайте

Из корня репозитория выполните, заменив `https://your-origin` адресом своей установки:

```sh
node scripts/nvidia-smoke.js https://your-origin
```

Успешный прогон делает **три настоящих AI-вызова**: объяснения сценариев A/B и разбор текстового плана. Он расходует квоту выбранного сервера, проверяет `provider: "nvidia"`, идентификатор модели NVIDIA, точные Score A/B и состав допустимого плана. Результат должен содержать `ok: true`; для Workers AI проверьте `model: "@cf/nvidia/nemotron-3-120b-a12b"`. Наличие этой команды в инструкции не является подтверждением успешного живого прогона.

Откройте главную страницу своего сервера и введите:

> Оцени план: в Нуре построить школу с детсадом, открыть поликлинику и добавить освещение с камерами; во всём городе внедрить единую цифровую платформу обращений; в Сарыарке перевести частный сектор на чистое топливо. Используй только перечисленные меры. Проверь бюджет и покажи влияние на город.

Ожидаются `M7 / M8 / M10` в Нуре, городская `M12` и `M5` в Сарыарке: **стоимость 95, Score 56.54307**, ноль критических показателей. После успешного ответа модель подписана **NVIDIA Nemotron**. Перед применением проверьте предложенные меры. В ответе `/api/plan` должны быть `mode: "ai"`, `available: true`, `provider: "nvidia"`, указанная модель, `valid: true` и серверный `result`.

Для проверки именно объяснения откройте `/classic.html`, загрузите демо и рассчитайте его. Панель объяснения должна показывать **«AI-анализ · NVIDIA Nemotron»**, сильные стороны и риски. Ответ `/api/explain` должен содержать `mode: "ai"`, `available: true`, `provider: "nvidia"` и имя модели. Расчётное объяснение или `aiConfigured: true` в `/api/health` не заменяет эту проверку.

Повторите исходный текст целиком, изменив только район школы с **Нуры на Есиль**, остальные меры и районы сохраните. Стоимость останется **95**, Score станет **55.29777**, останется один критический показатель — школы и детсады Нуры. В объяснении должна измениться привязка школы и сохраниться риск для Нуры; фиксированная одинаковая проза не подтверждает осмысленный анализ.

Для проверки бюджета замените в исходном примере освещение и камеры на **городские умные светофоры**, сохранив остальные четыре меры. Стоимость **105** недопустима: сервер возвращает `BUDGET_EXCEEDED`, Score отсутствует. AI-план может иметь `mode: "ai"` и `available: true`, но при этом `valid: false`; применять его нельзя. Прямой недопустимый запрос `/api/simulate` или `/api/explain` получает HTTP 422 до обращения к модели.

Фиксируйте время проверки, ревизию, HTTP-статус, `provider`, `model`, режим и результаты A/B. Автоматические тесты с подставными ответами проверяют интеграцию, но не подтверждают доступность Workers AI или NVIDIA NIM. Успешный внешний вызов и доступность квоты проверяются отдельно.
