## HTTP

Все ответы API — JSON. Никакие поля клиента не меняют бюджет/данные/формулу.

| Маршрут | Запрос | Ответ |
|---|---|---|
| GET /api/health | — | `{ok:true, aiConfigured:boolean}` |
| GET /api/dataset | — | `getDataset()` |
| GET /api/baseline | — | `getBaseline()` |
| POST /api/validate | `{decisions:[{measureId,districtId?}]}` | `validateScenario()`; 200 для любого результата валидации |
| POST /api/simulate | тот же | `simulate()`; 200 валидный, 422 невалидный |
| POST /api/explain | тот же | `{mode:'ai'|'deterministic', available:boolean, summary, strengths:[], risks:[], recommendations:[], ...}`; сервер заново считает сценарий; невалидный 422 |

`districtId` отсутствует для городских мер. `errors` содержит `{code,message,decisionIndex?}`. Неполный черновик валидируется, ошибка `DECISION_COUNT` блокирует расчёт, остальные ошибки блокируют добавление/изменение.

AI-интерфейс: `explainScenario(scenario, result, options?)` из `src/ai/explain.js`, Promise JSON. `isAIConfigured()` сообщает только наличие ключа. Модуль обязан вернуть честно обозначенное детерминированное объяснение при отсутствии ключа/ошибке API; оно не считается проверенным LLM-анализом.

Статика только из `public/`: `/` → `index.html`; доступ к `.env`, исходникам и данным через произвольные пути запрещён. Лимит тела JSON 32 KiB. Сервер экспортирует `createAppServer(options?)`, обычный запуск `node --env-file-if-exists=.env.local src/server.js`, порт 3000, host 127.0.0.1 по умолчанию.

Секреты только на сервере. Для LLM передаются выбранные меры и рассчитанные показатели официального синтетического набора. Числовые карточки интерфейса всегда используют ответ симулятора. Ответ AI для старого выбора не должен заменять текущий результат.

## Панель сравнения Алишера

`public/comparison.js` — ES module, создаёт интерфейс внутри `<section id="comparison-panel">`. Стили только с префиксом `.comparison-`. Подключение JS/CSS в index делает интегратор после готовности файлов.

- Главный UI после успешного расчёта отправляет `window.dispatchEvent(new CustomEvent('scenario:calculated', { detail: { scenario: { decisions }, result } }))`.
- Панель хранит до двух валидных результатов в слотах A/B в памяти страницы: первый в A, второй в B, далее прежний B становится A, новый результат — B. Снимки независимые. Показывает Score, стоимость, остаток, число критических показателей, худший район и разницу по районам. Числа берёт из `result`, формулу заново не реализует; районная разница — B.afterScore минус A.afterScore для одинакового district.id.
- Кнопка «Загрузить» отправляет `window.dispatchEvent(new CustomEvent('scenario:load', { detail: { scenario } }))`.
- Главный UI валидирует загружаемый выбор сервером, обновляет пять решений и сбрасывает устаревший результат. Расчёт запускается пользователем.
- Пустые слоты имеют понятную подсказку; DOM заполняется безопасно текстом. Модуль не вызывает AI, не читает ключи и не импортирует Node-ядро.
