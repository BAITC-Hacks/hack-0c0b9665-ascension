# Меню Telegram-бота

`/start` и `/menu` открывают главное меню. Все основные действия доступны кнопками: новое обращение, проверка статуса, помощь и техподдержка. При наличии черновика появляется кнопка его продолжения. Команды предыдущей версии (`/agree`, `/address`, `/send`, `/status НОМЕР КОД`, `/cancel`) продолжают работать.

Новое обращение: согласие → описание → необязательный адрес или геолокация → необязательные фото → просмотр → явная отправка. Кнопка геолокации запрашивает текущую точку только при нажатии пользователя; для проблемы в другом месте можно ввести адрес или выбрать точку через скрепку. Кнопка фото объясняет прикрепление через скрепку. Текст адреса вводится отдельным шагом и не добавляется к описанию.

Главное меню, помощь и статус сохраняют черновик. В главном меню случайный текст не дописывается в существующее обращение: сначала нужно нажать «Продолжить обращение». Создание нового обращения при существующем заполненном черновике требует отдельного выбора «Начать заново». Отмена удаляет только незавершённый черновик. Черновики живут 30 минут бездействия и теряются при перезапуске сервера; отправленные обращения сохраняются.

Проверка статуса сначала просит номер, затем принимает его отдельным сообщением. Без кода доступно только обращение, принадлежащее этому же Telegram-чату. Для обращения с сайта нужны номер и личный код. Ответ не раскрывает исходный текст, адрес, фото и личный код.

## Техподдержка

Необязательная переменная `TELEGRAM_SUPPORT_URL` в игнорируемом `.env.local`: Telegram-ссылка на назначенный контакт или чат (`https://t.me/username`), либо `@username`. После изменения перезапустите сервер. Без контакта бот честно показывает, что оператор не подключён, и ответы на частые вопросы. Раздел не принимает заявки в поддержку и не пересылает сообщения другим людям.

## Регистрация стандартного меню Telegram

После запуска обновлённого сервера один раз выполните из корня проекта:

```powershell
npm run bot:setup
```

Для другого компьютера с Node.js 24+ в PATH: `node --env-file=.env.local src/telegram-setup.js`.

Скрипт регистрирует команды для личных чатов через `setMyCommands`, стандартную кнопку через `setChatMenuButton` и приветственное описание через `setMyDescription`. Он не рассылает сообщения. Клавиатура с кнопками приходит в ответ на `/start`, `/menu` или другие действия пользователя.

Для локальной работы по-прежнему нужны один сервер и один polling-процесс; оба читают один `.env.local`. При обновлении сначала остановите polling, затем перезапустите сервер и снова запустите polling. Секреты, логи и реальные обращения не добавляют в Git.

## Проверка

Автоматические тесты используют синтетические обновления и подставной Telegram-транспорт: полный путь по кнопкам, отдельный ввод адреса, просмотр без отправки, повторное обновление, сохранение черновика при навигации, явное начало заново, проверка владельца при поиске статуса, честный режим поддержки без контакта и регистрация стандартных команд. Для живой проверки отправьте `/menu` своему боту и пройдите те же шаги с явно тестовым обращением.
