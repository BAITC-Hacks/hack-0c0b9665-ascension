## Что объяснить на демо

**A** — лучший основной показ: три решения направлены в слабейшую Нуру. M7 и M8 поднимают S1 на 10 и S2 на 8.75; M10 вместе с M12 даёт в Нуре B1 +12.5, включая синергию +2. M5 улучшает воздух Сарыарки (E2 +8.75), а M12 поднимает C2 каждого района на 4.375. Оба критических показателя Нуры исчезают. Риск: транспорт не улучшается, а 5 единиц бюджета не дают бонуса.

**B** стоит на 34 меньше A, но Score ниже на 2.61549. Сильнее всего растёт Есиль (+2.9125 районного балла): M4 улучшает экологию, M10 — безопасность, синергия M10+M12 здесь достаётся Есилю. M9 слабо помогает социальным показателям Нуры; S2 остаётся 37.625. M11 поднимает B2 Алматы на 10.5, но снижает T1 на 1.75 — с 40 до критических 38.25. Поэтому критических показателей снова два. Неизрасходованные 39 единиц бюджета сами по себе Score не повышают.

**C** использует весь бюджет и даёт Score на 1.47018 выше B, но на 1.14531 ниже A. M1+M2 улучшают транспорт Нуры: T1 +9.5 (включая синергию +2), T2 +6.75; M2 также поднимает T1 и B2 во всех районах. M5 работает на воздух Сарыарки, M4 — на экологию Есиля, M8 — на медпомощь Нуры. S1 Нуры остаётся 38 и критическим: максимальный расход не заменяет адресный выбор мер.

Для короткого демо: загрузить A и получить 56.54; затем B и показать разницу Score, районов и риск переходов в Алматы; при наличии времени загрузить C и показать, что полный расход не обязательно лучше A. ## Как повторить расчёт

Из корня клона с Node.js 24+ выполните в PowerShell (для A/B/C/D порядок мер значения не меняет):

```powershell
@'
import { validateScenario, simulate } from './src/core/simulator.js';
const cases = {
  A: [['M7','nura'],['M8','nura'],['M10','nura'],['M12'],['M5','saryarka']],
  B: [['M9','nura'],['M11','almaty'],['M10','esil'],['M12'],['M4','esil']],
  C: [['M1','nura'],['M2'],['M4','esil'],['M5','saryarka'],['M8','nura']],
  D: [['M3','nura'],['M5','saryarka'],['M7','nura'],['M10','esil'],['M12']],
};
for (const [name, choices] of Object.entries(cases)) {
  const decisions = choices.map(([measureId, districtId]) =>
    districtId ? { measureId, districtId } : { measureId });
  const validation = validateScenario({ decisions });
  const result = simulate({ decisions });
  console.log(name, JSON.stringify({
    validation,
    score: result.score ?? null,
    remainingBudget: result.remainingBudget ?? null,
    criticalCount: result.criticalCount ?? null,
    districts: result.districts?.map(({id, afterScore}) => ({id, afterScore})) ?? null,
  }));
}
'@ | node --input-type=module
```

На этой машине `node` отсутствует в системном PATH. Для фактического запуска выше использован Node.js 24.19.0 из bundled runtime Codex вместо команды `node`; при повторении без Node в PATH нужно указать путь к своему исполняемому файлу Node.js 24+. Дополнительно на той же ревизии `node --test`: **63 пройдено, 0 ошибок**. HTTP и UI для этих четырёх входов отдельно не проверялись; тесты AI используют подставные ответы и не доказывают работу живого провайдера.
