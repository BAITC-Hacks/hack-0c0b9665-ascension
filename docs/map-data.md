# География, карта и источники

Карта использует реальные улицы, водоёмы и здания OpenStreetMap через OpenFreeMap. Встроенные города и регионы — координатные закладки камеры, а не наборы городских показателей или официальные границы. Поиск Photon позволяет перейти к другим городам и регионам.

## Разделение географии и модели

- Математическая модель остаётся официальным синтетическим набором из `data/city.json`. Она содержит пять районов Астаны и не заявляет актуальную административную структуру или реальные измерения города.
- Значение, цвет числовой метки и панель района берутся из серверных `baseline` / `result`. Слой «До / После» переключает `before` / `after`, общий балл — `beforeScore` / `afterScore`. Формула не рассчитывается заново в карте.
- Пять меток — приблизительные точки для размещения подписей. Они не являются центроидами, адресами проблем или координатами исполнения мероприятий. В 2D добавлены **условные секторы учебной модели**, а не административные границы: `public/district-sectors.js` делит нарисованный контур по ближайшей метке (ячейки Вороного, с поправкой долготы на широту). Это явно указано над и под картой. Для показа реальных границ нужен отдельный проверенный географический источник.
- У каждого сектора свой постоянный цвет, независимо от оценки. При наведении появляется подсветка и подсказка с текущим показателем; нажатие выбирает район. Карточки под картой дают тот же выбор с клавиатуры и телефона. Цвет числовых меток по-прежнему соответствует шкале показателя, поэтому смена слоя данных не меняет идентичность районов.
- Карта открывается в 2D с обзором всех пяти секторов. «Все районы» и кнопка общего вида восстанавливают обзор, выбор карточки приближает сектор. Секторы можно скрыть; в 3D они скрываются автоматически, сохраняя выбор зданий, улиц и транспорта. На телефоне подробности выбранного района расположены под картой, кнопки масштабирования увеличены. В списке районов работают Tab, стрелки, Home/End и Enter.
- Для другого города или региона доступны география, поиск и 3D. Местные оценки отсутствуют: показатели Астаны не переносятся на выбранную территорию. Чтобы использовать систему для реального управленческого решения, необходимы местные проверенные данные, бюджет, калибровка эффектов и актуальная геометрия районов.
- 3D — экструзия контуров зданий из слоя OpenMapTiles `building`. Высота берётся из `render_height`, основание — `render_min_height`. При отсутствии высоты используется условная высота 3 м. Это обзор, не инженерная модель.

## Внешние сервисы

Проверено 23 сентября 2026:

1. [OpenFreeMap](https://openfreemap.org/) предоставляет публичную карту без API-ключа и платы за просмотры; SLA не заявлен. Используется стиль [Positron](https://tiles.openfreemap.org/styles/positron). Интеграция следует [Quick Start](https://openfreemap.org/quick_start/). Шрифты, спрайты, растровая подложка и векторные тайлы загружаются только с `https://tiles.openfreemap.org`.
2. [Photon](https://github.com/komoot/photon#demo-server) разрешает API публичного демосервера для проектов при разумном количестве запросов, без гарантии доступности. Поиск выполняется только после нажатия «Найти» или Enter, не при наборе текста. Один активный запрос, интервал не меньше 1,6 секунды между сетевыми запросами, таймаут 12 секунд, до 30 ответов в памяти страницы, максимум 6 результатов. Встроенные закладки обходят сеть. Для большого числа пользователей нужен собственный Photon или поставщик с согласованной нагрузкой. [API](https://github.com/komoot/photon/blob/master/docs/api-v1.md).
3. Публичный Nominatim не используется. Поисковому сервису отправляются только введённое название и координата центра выбранной территории; не передаются решения, показатели, API-ключи или точная геолокация пользователя. Поиск не запрашивает местоположение устройства.

Для работы в браузере CSP должен разрешать `connect-src 'self' https://tiles.openfreemap.org https://photon.komoot.io`, `worker-src 'self' blob:`, `img-src 'self' data: blob: https://tiles.openfreemap.org`; библиотека и CSS загружаются с собственного сервера. MapLibre применяет встроенные стили элементов; политика style-src должна это учитывать.

## Контракт интеграции

Подключить `/map.css`, импортировать `createCityMap` из `/map.js` и после получения датасета и базы вызвать:

```js
const cityMap = createCityMap({
  container: document.getElementById('city-map'),
  dataset,
  baseline,
  onDistrictSelect: (districtId) => { /* выбрать район в плане */ },
});
cityMap.setResult(result); // null при изменении плана
cityMap.setCity('astana');
cityMap.focusDistrict('nura');
```

Событие окна `city:changed` содержит `{id,name,center,kind,hasScenarioData}`. Только `hasScenarioData: true` разрешает интерфейсу показывать модель Астаны в контексте выбранной территории. Другие города требуют спрятать или отключить панели модели. Дополнительно возвращаются `ready` (завершение инициализации клиента, не гарантия загрузки тайлов) и `destroy()`.

При сбое библиотеки, WebGL или длительной загрузке показывается явная заглушка и повтор загрузки. Текстовый список районов и числа остаются доступны; таблица модели не зависит от загрузки географии. Сервер должен отдавать JS, CSS и LICENSE как обычную публичную статику.
