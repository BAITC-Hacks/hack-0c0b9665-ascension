# Visual system · case 12

`public/visual-design.css` — отдельный визуальный слой для существующего DOM. Подключать **после** `styles.css`, `dashboard.css` и всех компонентных CSS (`map`, `comparison`, `scenario-library`, `policy-options-panel`), **перед** `motion.css`.

Hero использует декоративный `/assets/design/city-grid.svg`, `.city-symbol` — `city-emblem.svg`, placeholder результата — `scenario-lines.svg`. SVG сохраняют пропорции через `background-size`; контент в них не дублируется. В sidebar прежний декоративный SVG прозрачен. Ассеты предоставляются отдельным коммитом `4497128`.

Тёмная карточка выделяет исходный Score; каталог, план, результаты, сравнение, библиотека и альтернативы используют согласованные controls, типографику и границы. Большинство основных кнопок/полей имеют высоту 44 px. На mobile текстовые поля и select плана имеют 16 px. Фокус различим также в sidebar и самостоятельных компонентах.

Поддержаны оба положения единственного `#district-focus`: исходное внутри карты и `#app > .district-focus` перед обзорными метриками. Во втором положении mobile показывает вводную и три приоритета двумя колонками, CTA занимает строку ниже. DOM переставляет интегратор.

## Проверка 23 сентября 2026

Локальный preview на `127.0.0.1:3031` использовал исходный сервер/DOM базы `56c5150`; CSS, mounting двух дополнительных панелей и перенос priority добавлялись только в отдаваемый HTML. Source wiring не изменён. Графика прочитана из worktree `city-graphics`.

- Визуально проверены desktop 1280 px и изолированные iframe 1024, 768, 390 px. `documentElement.clientWidth / scrollWidth`: `1265/1265`, `1009/1009`, `753/753`, `375/375` соответственно (15 px вертикальный scrollbar). Горизонтального переполнения страницы нет. Таблица и список районов сохраняют собственную прокрутку.
- На 390 px проверены hero, приоритеты, обзор, заполненный план, результат, сравнение, библиотека и состояние недоступного API альтернатив. CTA приоритетов виден в первом экране высотой 720 px при переносе блока перед обзором.
- Официальное демо через UI: 5 мер, стоимость `95`, остаток `5`, Score `56,54`, прирост `3,99`, критических показателей `0`. Расчётное объяснение корректно отделено от AI.
- Tab от поля названия сценария переводит фокус на «Сохранить расчёт»; `:focus-visible` активен, зелёный outline видим. Элементы `[hidden]` не занимают места.
- Контраст основных пар: вторичный текст/поверхность `5,37:1`, подпись/тёмная метрика `7,48:1`, белый/главная кнопка `6,63:1`. Это выборочная проверка токенов, не полный аудит WCAG.
- `git diff --check` проходит. В CSS нет `@import`, animation/transition, правил `[hidden]`, canvas/stage/marker geometry. JS, данные, HTML и зависимости не изменены.

## Интеграционные ограничения

На исходной базе длинный sticky-план выходит за desktop viewport; интегратор уже подготовил его max-height/scroll в новом `dashboard.css`. Этот слой их не переопределяет. Исходный mobile `order:-1` сохранён; порядок плана и каталога в DOM следует согласовать отдельно при общей правке HTML.

Полный расчёт альтернатив не был подключён на сервере preview базы `56c5150`: проверено его доступное сообщение ошибки и сохранение основного результата. Итоговые мобильная навигация, карта/3D, анимации и функциональность новых панелей проверяются интегратором после объединения. Числовой модуль не менялся; повторный полный unit suite для CSS не запускался.
