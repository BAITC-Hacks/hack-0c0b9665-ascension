# Полнота UI для общего выпуска

23 сентября 2026. По указанию пользователя публикацию на **https://ascension-city-map.azamatbreach.workers.dev/** выполняет **Азамат**. Этот набор подготовлен в отдельном worktree от `origin/main` (`898b9c8`, обновлён до `4947a81`) и объединяет UI PR #21 (`1dc1858`). Исходные commits обоих участников сохраняются. Общая рабочая ветка, main и опубликованный Worker не изменены.

Этот UI-кандидат не включает конкурирующие облачные реализации PR #25/#28, не добавляет Durable Object и не переключает Telegram. Решение о каноническом реестре остаётся у координатора в [issue #18](https://github.com/BAITC-Hacks/hack-0c0b9665-ascension/issues/18). Совместимость кабинетов описана в [контракте](desk-complaints-contract.md).

## Что должно попасть в выпуск

- `/`: карта с выбором территории, конструктор с поиском/сортировкой/фильтрами, отмена изменения и черновик, расчёт, объяснение бюджета, экспорт JSON/CSV, печать и ссылка на сценарий, альтернативы, сравнение A/B, общая библиотека, районы и методика.
- `/citizens.html`: подача обращения, координаты, приватная квитанция, отслеживание и ссылка на Telegram.
- `/mayor.html`: защищённая панель реальных обращений, фильтры, назначение, статусы, история и карта.
- `/desk.html`: командная сессия, журнал, карточка, вложения, CSV и сохранённые сценарии.
- `/akim.html`: все пять вкладок `#summary`, `#problems`, `#tasks`, `#decisions`, `#meeting`, переключение RU/KZ, поручения, контроль и отчёт.
- `/resident.html`: персональная ссылка, публичный ответ, подтверждение/оспаривание и фото.
- `/results.html`: опубликованные результаты, фильтры и фото до/после.
- `/demo.html`: демонстрация по шагам с расчётами двух вариантов.

Дополнительно подключены ранее не смонтированные модули `action-register`, `decision-brief`, `evidence-register`. Реестр ручных действий и источники доступны и при географическом просмотре другого города; модельные результаты сбрасываются по прежним событиям смены города/сценария. Библиотека сценариев остаётся единственной, с прежним ключом `akim-scenario-library-v1`.

Меню «Все разделы» даёт доступ ко всем восьми страницам и вспомогательным панелям, в том числе на телефоне. Ссылки с параметрами обращения, поручения и сохранённого сценария сохраняются.

## Иллюстрации

Включить **весь** каталог `public/assets/illustrations/` — 28 WebP — вместе с `public/illustrations.css`, ссылками в `index.html` и отображением в `app.js`. Это 25 разных иконок: 14 инициатив, 5 районов, 4 показателя, 2 пустых состояния; ещё 3 изображения используются как фоны. Промпты и распределение: [generated-artwork](ux/generated-artwork.md), [unique-artwork](ux/unique-artwork.md).

Нельзя переносить только WebP или только HTML: до этого выпуска на live и файлы, и stylesheet возвращали 404, а подключения в HTML отсутствовали. Участки карты не заменяются изображениями; интерактивная карта остаётся прежней.

## Проверка перед публикацией

В согласованной версии выполнить `npm test`, `node scripts/check-quality.js`, `npm run check:policy-worker`, `npm run check:release`, затем `npx --yes wrangler@4.136.3 deploy --dry-run`. Проверять именно финальный checkout после включения остальных командных PR.

`check:release` проверяет восемь HTML, локальные ресурсы, отсутствие конфликт-маркеров, 25 уникальных иконок и пять вкладок акима. После публикации запустить `RELEASE_BASE_URL=https://ascension-city-map.azamatbreach.workers.dev npm run check:release`. Это read-only smoke; он отличает HTML 200 от работающего JSON API и не создаёт обращений/пользователей.

Проход по браузеру: открыть все восемь страниц; проверить иконки на широком экране и 320px; рассчитать демо, сохранить и загрузить сценарий, сменить город и вернуться; пройти пять вкладок акима с согласованной тестовой учётной записью. Изменения реальных обращений и проверку Telegram выполняет владелец после безопасной миграции.

## Что нельзя объявлять готовым раньше времени

Кабинеты PR #21 используют Node/SQLite и пока не адаптированы к Worker. HTML и навигация сохраняют все страницы, но сами по себе не включают `/api/desk/*`, `/api/resident/*` и `/api/public/results`. Реестр настоящих обращений нельзя подменять демонстрационным. Публикация всех разделов как полностью рабочего единого процесса требует согласованного адаптера из контракта и проверки старых приватных квитанций.

Не сбрасывать существующие `AIBudget`/миграцию `v1`, bindings, secrets или данные. Не выполнять переключение Telegram при переносе UI. Зафиксировать итоговый SHA, Cloudflare version ID, результат smoke и оставшиеся ограничения в issue #18; commit/push/dry-run не являются публикацией.
