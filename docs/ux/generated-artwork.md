# Generated interface artwork

Generated on 2026-09-23 with the built-in GPT Image tool (`image_gen`). The tool does not expose a selectable model version, so the requested “2.5” version cannot be verified. No CLI/API fallback was used.

Nine original compositions: seven transparent icons and two backgrounds. Project assets live in `public/assets/illustrations/`; icon exports are 256px WebP with alpha preserved. The city hero also has a 768px responsive export. No text or numeric data is baked into the art. These are decorative illustrations, not an accurate map of Astana.

## Placement

- `budget.webp`: total and unallocated budget metrics.
- `services.webp`: baseline city metric and city service measures.
- `transport.webp`, `ecology.webp`, `people.webp`, `safety.webp`: corresponding measure categories.
- `plan.webp`: scenario count and empty planning state.
- `people.webp`: residents in district headers and results placeholder.
- `city-hero.webp` / `city-hero-mobile.webp`: responsive hero artwork.
- `city-texture.webp`: results placeholder and score methodology background.
