# Unique initiative and district illustrations

Expansion of the initial set on 2026-09-23, following the request to eliminate repeated icons. Generated with the built-in `image_gen` tool; no CLI/API fallback and no selectable model-version claim. All final project assets are in `public/assets/illustrations/` as 256px transparent WebP.

## Design and mapping

Each of the 14 initiative cards now has its own subject. The category remains a written, colored tag; the image illustrates the specific initiative. All four summary metrics have different icons. The five district cards use distinct abstract architectural miniatures, not accurate district landmarks or geographic maps. People and the folded map remain only in the results and planning empty states respectively.

- M1: `transport.webp` — bus.
- M2: `traffic-lights.webp` — adaptive signal.
- M3: `light-rail.webp` — rail tram.
- M4: `ecology.webp` — park tree.
- M5: `clean-heating.webp` — house and clean leaf.
- M6: `green-belt.webp` — windbreak planting.
- M7: `school.webp` — school and children's blocks.
- M8: `clinic.webp` — clinic and stethoscope.
- M9: `sports.webp` — basketball hoop and ball.
- M10: `safety.webp` — protective shield.
- M11: `safe-crossing.webp` — pedestrian crossing.
- M12: `digital-service.webp` — resident request on a smartphone.
- M13: `utilities.webp` — radiator and water pipe.
- M14: `emergency-crew.webp` — repair tools and amber beacon.
- Metrics: `services.webp`, `budget.webp`, `budget-remaining.webp`, `decision-checklist.webp`.
- Districts: `district-yesil.webp`, `district-almaty.webp`, `district-saryarka.webp`, `district-baikonur.webp`, `district-nura.webp`.
- Empty states: `plan.webp`, `people.webp`.

The complete default simulator view therefore uses 25 different icon files with no duplicates. Backgrounds are shared separately and are not icon slots.
