## Регламент выступления

Основная речь рассчитана на **6 минут 20 секунд** без живой демонстрации. Для общего регламента до 7 минут заменить рассказ по слайдам 4 и 5 демонстрацией на 90 секунд: общий маршрут займёт около **6 минут 40 секунд**. После уже проведённого демо завершить выступление приглашением к вопросам.

Слайды 13–18 предназначены для технических вопросов и не входят в основную речь. Перед выступлением проверить фактическую версию демонстрационного стенда и при необходимости обновить исторические статусы готовности.
