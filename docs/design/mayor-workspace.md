# Рабочее пространство городских решений

Новый кабинет объединяет обзор города, карту, конструктор, результаты, районы, библиотеку, обращения, поручения и паспорта данных в девять отдельных адресов. Вход: `/mayor-overview.html`.

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/mayor-overview.html` | Панорама, исходные или рассчитанные показатели, приоритет слабейшего района |
| `/mayor-map.html` | Существующая карта, здания, условная транспортная анимация и маршруты |
| `/mayor-planner.html` | 14 мер, выбор пяти решений, бюджет, районы и серверная валидация |
| `/mayor-analytics.html` | Результат, влияние на районы, объяснение по запросу, сравнение A/B и альтернативы |
| `/mayor-districts.html` | Оценки пяти районов и полная таблица десяти показателей |
| `/mayor-scenarios.html` | Существующая библиотека, импорт и экспорт, записка к совещанию |
| `/mayor-requests.html` | Существующий кабинет обращений Астаны с его защитой доступа |
| `/mayor-tasks.html` | Существующий ручной реестр поручений |
| `/mayor-data.html` | Формула, ограничения и существующие паспорта наблюдений |

Каждый адрес открывается напрямую. Внутренние ссылки используют History API и сохраняют модули в памяти: рассчитанные сценарии A/B не теряются при переходе между разделами. После полной перезагрузки восстанавливаются только выбранные решения; они заново проверяются сервером. Результат и объяснение повторно запрашиваются пользователем. Долговременные сценарии сохраняются в библиотеке.

## Интеграция

Основа: `49c590ffd783b6a5c21d5e06776d4d59c93b2704`. Все добавления изолированы в `public/mayor-*`, `public/assets/mayor`, `docs/design/mayor-*` и `tests/mayor-planner.test.js`. Общие `index.html`, `app.js`, API, ядро, данные и настройки хостинга не изменены.

Новый `mountMayorPlanner` использует `/api/validate`, `/api/simulate`, `/api/explain` и канонические события `scenario:calculated`, `scenario:invalidated`, `scenario:load`, `city:changed`. Числовые результаты не рассчитываются повторно на клиенте. Объяснение вызывается только отдельной кнопкой. Ошибки и запоздалые ответы не заменяют текущий план.

Карта и все дополнительные панели импортируются из существующих модулей. Существующее содержимое `/mayor.html` загружается из того же origin и подключает штатный `mayor.js`; это сохраняет фильтры, авторизацию, историю и конфликты версий. iframe не используется, политика безопасности не ослаблена. Персональный токен остаётся в памяти модуля обращений.

Публикация добавляет новые статические файлы. Владелец основного интерфейса может добавить ссылку на `/mayor-overview.html`; переключать основной `/` для работы кабинета не требуется. Ссылка карты «Открыть основной симулятор» ведёт к актуальному общему интерфейсу, включая расширения следующего релиза.

## Достоверность

Показатели и приоритеты — синтетический набор Астаны. Другие города имеют только географический просмотр; смена города отменяет актуальность расчёта. Очередь обращений явно обозначена как очередь Астаны. Условные единицы не переводятся в тенге. Панорама декоративная и не служит географическим доказательством. Для реального муниципального применения нужны местные данные, проверка источников и калибровка модели.

## Проверка

Локальная проверка: Node 24, отдельный сервер `http://127.0.0.1:3087`, Microsoft Edge через Playwright.

- 8/8 тестов жизненного цикла конструктора: официальный пример, явный запрос объяснения, устаревшие ответы, параллельная валидация, восстановление черновика, смена города, удаление обработчиков и районный контекст.
- 20/20 браузерных проверок: прямое открытие девяти адресов; демо 95 у. е. и Score 56,54; сохранность результата после перехода на карту; блокировка модели другого города; поиск и кнопка браузера «Назад»; шесть разделов на ширине 390 px без горизонтального переполнения; отсутствие необработанных ошибок и автоматических AI-вызовов.
- Обзор, конструктор и результат проверены визуально на настольной ширине 1440 px, обзор также на 390 px. Доступны клавиатурный фокус, мобильное меню, Escape, поиск разделов и reduced motion.
- HTTP/ядро/старые модули не менялись, их полный набор тестов здесь не запускался повторно. Живой внешний LLM, реальные входящие обращения и доступность всех картографических сервисов этой проверкой не подтверждаются.
