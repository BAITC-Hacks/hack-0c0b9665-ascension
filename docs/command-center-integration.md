# Подключение command center

Страница `command-center.html` использует общий `app.js` и атрибут `body data-command-center="true"`. После получения датасета, создания карты и подключения библиотеки, альтернатив, поручений, записки и паспортов приложение динамически импортирует `command-center-bridge.js` и вызывает `mountCommandCenterBridge`. Основная страница использует эту же разметку после интегрированной проверки; компактный интерфейс сохранён в `classic.html`.

Передаются `dataset`, `baseline`, `map`, существующие `applyDecisions` и `calculate`, а также `getContext()`. Контекст содержит доступность модели, версию плана, выбранный город, признак успешного результата и отдельные копии текущих решений. Мост работает через существующие проверку, расчёт и события приложения; прямого изменения состояния или дополнительных AI-вызовов в подключении нет.

На компактной странице без указанного атрибута импорт и mount не выполняются. Карта создаётся при открытии её блока, сохраняет первоначальный режим 2D и уже рассчитанный результат. В command mode `ensureMap()` обходит закрытый блок и создаёт карту до подключения оболочки.

## Первоначальный режим карты

Первоначальным переключением в 3D владеет оболочка command center: исправление PR #41 включено в интеграцию. В `app.js` нет дублирующего нажатия кнопки; публичный API карты не расширяется. Компактная страница сохраняет исходный режим 2D.

Существующий обработчик карты сохраняет режим даже до загрузки стиля. После `load` карта применяет `set3D(true)` и включает explorer, поэтому ранний вызов штатной кнопки из оболочки не оставляет плоскую камеру. Итоговый режим проверяется в браузере после объединения PR #41.

## Повторная инициализация и ошибки

Disposer моста добавляется последним в общий список. Очистка идёт в обратном порядке: сначала оболочка возвращает перемещённые DOM-узлы, затем удаляются панели, после них уничтожается карта. Ошибка одного disposer не останавливает остальные. При ошибке импорта или инициализации освобождаются уже созданные ресурсы, содержимое приложения скрывается, показывается существующая кнопка повторной загрузки.

Идентификатор инициализации проверяется после получения исходных данных и после динамического импорта. Устаревшая попытка не монтирует вторую оболочку и не очищает ресурсы более новой попытки. Проверки версий в `applyDecisions`, `calculate`, объяснении и событиях смены города не изменены.

## Проверка

Целевые команды:

```sh
node --check public/app.js
node --test tests/command-center-bridge.test.js tests/trajectory.test.js
git diff --check
```

Целевые тесты проверяют применение через валидацию, серверные кадры, отмену устаревшей динамики и очистку bridge, начало и конец траектории. Они не заменяют интегрированную проверку страницы. Для неё: открыть command center и убедиться в режиме 3D; применить демо, рассчитать и выбрать квартал; сменить город во время запроса; вернуться и пересчитать; проверить обычную страницу в 2D. Живой платный AI этими командами не вызывается.

На базе `5ef36e0` после подключения: **16/16 целевых тестов PASS**. После объединения PR #41, #42 и #43: отдельная проверка city-race/bridge — **9/9 PASS**; качество — **115 JS, 177 относительных импортов, 5 общих защитных заголовков PASS**. Проверка выполнялась на настоящем Node-сервере `127.0.0.1:3047`, без API-ключа и без подмены маршрута траектории: демо даёт стоимость 95 и Score 56.54, конечный кадр совпадает с расчётом. Квартал 0 возвращает исходное состояние, смена города очищает старую траекторию, отсутствие ключа показано честно. Полноэкранная карта проверена при 1280×800 и 390×844 без горизонтального переполнения.

Разметка PR #43 используется обеими страницами. Панели записки, поручений и паспортов находятся по ID, даже если их контейнеры вложены в компактные `details`; сведения о районах и методика раскрываются в боковой панели. Компактный заголовок скрыт также из навигации клавиатурой при работе оболочки.

Сброс плана выполняется локально и доступен при ожидающей проверке: очищает решения, бюджет, выбор районов и результат, увеличивает поколения запросов. Ответ старой проверки или расчёта не может восстановить очищенный план. `tests/app-reset.test.js` вместе с city-race: **6/6 PASS**, включая отсутствие сети, ожидающую первую меру и поздний отказ проверки.

## Общий реестр поручений

Обе страницы подключают `team-workspace.css` и содержат `#team-workspace-panel`, не относящийся к учебной модели. После локального реестра `app.js` монтирует панель с `getDocument` и `applyDocument`; при отсутствии контейнера подключение пропускается. Disposer общей панели вызывается до локального реестра. При открытии выполняется только проверка сессии; локальный документ отправляется после явного действия пользователя. Оболочка показывает панель в инструментах. Поручения, паспорта и общий реестр можно открыть без переключения с выбранного города на Астану.

Проверка подключения, сброса, city-race и bridge: **35/35 PASS**. Состояние публичного доступа зависит от отдельно проверяемой серверной конфигурации; наличие mount не означает завершённой проверки совместной работы.
