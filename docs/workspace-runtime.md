# Подключение общего реестра к HTTP

Node и Cloudflare Worker маршрутизируют точный `/api/workspace` и префикс `/api/workspace/` в один `createWorkspaceHandler`. Соседние пути, симулятор и обращения сохраняют собственные контракты. Правила сессий, ролей, схемы, конфликтов и транзакций находятся в [сервисе реестра](workspace.md), а транспортные адаптеры выбирают хранилище и передают доверенные метаданные.

Без валидных `WORKSPACE_ORIGIN`, `WORKSPACE_SESSION_SECRET` и `WORKSPACE_ACCESS_POLICY` запрос получает `503 WORKSPACE_DISABLED` до обращения к хранилищу. Неисправное хранилище или binding даёт `503 WORKSPACE_UNAVAILABLE`. Ответы сохраняют фактический HTTP-статус, cookie, `Allow` и `Retry-After`; заголовки безопасности приложения и `Cache-Control: no-store` применяются поверх ответа сервиса. HEAD сохраняет метаданные и не отправляет тело.

## Node

`src/runtime/node-workspace.js` открывает SQLite только при первой операции репозитория. Импорт модуля, выключенный доступ и анонимное чтение не создают базу. Путь выбирается из `WORKSPACE_DB_PATH`, затем параметра `workspaceDbPath` функции `createAppServer`, затем `var/workspace.sqlite` относительно репозитория. Для развёртывания нужен постоянный диск. Родительский каталог создаётся адаптером; база внутри фактического `publicDir` запрещена с проверкой реальных путей и существующих предков.

`src/runtime/node-web-handler.js` преобразует Node HTTP в Web Request/Response. Тело читается по требованию сервиса, поэтому проверки конфигурации, Origin и доступа завершаются до чтения JSON. Превышение лимита 128 КиБ возвращает 413, не уничтожая соединение до ответа; оставшиеся данные дренируются. Симулятор продолжает применять отдельный лимит 32 КиБ. Запись ответа учитывает обратное давление, отдельные Set-Cookie и отключение клиента.

URL строится только на настроенном `WORKSPACE_ORIGIN`, фактические Origin и Cookie сохраняются. Адрес для ограничения входа берётся из `socket.remoteAddress`; Host, Forwarded, X-Forwarded-For и внутренний Worker-заголовок не становятся доверенной конфигурацией. За общим proxy пользователи разделяют адресный лимит.

`createAppServer` закрывает SQLite при событии `close` сервера. При самостоятельном использовании `createRequestHandler` владелец HTTP-сервера вызывает `handler.close()` после остановки обработки запросов. Закрытие идемпотентно; последующий вызов обработчика не открывает базу повторно.

## Worker

`src/runtime/worker-workspace.js` проверяет ту же конфигурацию, затем вызывает `TEAM_WORKSPACE.getByName('team').fetch(request)`. Исходные URL, метод, тело, Origin и cookie сохраняются. Внутренний `X-Workspace-Client-Address` перезаписывается значением платформенного `CF-Connecting-IP` либо `unknown`. Авторизация выполняется в сервисе внутри DO; IP используется только для ограничения входа.

`src/cloudflare.js` экспортирует `TeamWorkspaceDurableObject`. Migration `v3-team-workspace` добавляет его SQLite-хранилище, сохраняя `v1` для AI budget и `v2-complaints` для обращений. Node SQLite не входит в Worker bundle. Настройки доступа в публичную конфигурацию не добавлены; для их включения необходимы отдельно выданные оператором значения.

## Проверка

```sh
node --test tests/node-web-handler.test.js tests/node-workspace.test.js tests/worker-workspace.test.js tests/workspace-routing.test.js tests/workspace-http.test.js
```

Транспортные тесты используют реальные локальные HTTP-соединения и SQLite: ранний отказ без тела, прерывание клиента, 413 с повторным использованием того же сокета, cookie/HEAD, перезапуск базы, отзыв сессии, подмена адресных заголовков и запрет базы в каталоге статики. Composition-тесты проходят через экспортируемые Node/Worker entrypoints. Подставной Worker binding не считается проверкой облачной инфраструктуры; отдельная проверка production bundle в локальном workerd фиксируется в evidence.

Проверки не включают выдачу рабочих ключей, публичную авторизованную сессию, резервное копирование или сквозную работу панели на опубликованном сайте. До настройки доступа публичный результат — честный 503, локальные записи пользователя остаются самостоятельными.
