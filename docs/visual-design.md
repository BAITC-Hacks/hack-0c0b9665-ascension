# Визуальный слой городского симулятора

Цель — сделать карту, бюджет и результат сценария проще для чтения, а выбор решений — понятнее через короткую визуальную обратную связь.

## Направление и источники

- [Linear: обновление интерфейса, 12 марта 2026](https://linear.app/changelog/2026-03-12-ui-refresh): единые контролы и более спокойная навигация. В проекте применяем согласованные отступы, контраст и иерархию панелей.
- [Vercel: Web Interface Guidelines](https://vercel.com/design/guidelines): видимый фокус, доступность с клавиатуры, короткие переходы transform/opacity и reduced motion. Движение дополняет состояние, а не задерживает доступ к нему.
- [Stripe: инженерный разбор интерактивного глобуса](https://stripe.com/blog/globe): схематичная географическая графика и визуальные связи. Это историческая статья 2020 года; она служит источником композиционного подхода, а не описанием текущей главной страницы Stripe.

Изображения, шрифты и код этих сайтов не заимствованы. SVG в `public/assets/design/` — собственные декоративные схемы, не географические данные и не результаты расчёта. Новых внешних runtime-зависимостей нет.

## Подключение

После существующих CSS приложения и компонентных панелей:

```html
<link rel="stylesheet" href="/visual-design.css">
<link rel="stylesheet" href="/motion.css">
<script type="module" src="/motion.js"></script>
```

`motion.js` инициализируется самостоятельно. Общие `app.js`, `index.html`, `dashboard.css` и файлы карты остаются в зоне владельца интеграции приложения. Визуальная ветка поставляет новые файлы; окончательное подключение проверяется на объединённой версии.

## Условия приёмки

- Первый экран, карта, каталог, план, результаты, сравнение, библиотека и поиск альтернатив сохраняют общую визуальную систему.
- При ширине 390 px страница не прокручивается горизонтально; широкая таблица может иметь собственную прокрутку.
- Значения Score и бюджета выводятся сразу без промежуточных выдуманных чисел.
- `prefers-reduced-motion` отключает добавленное движение. Клавиатурный фокус остаётся видимым; скрытые элементы модели не появляются для городов без данных.
- Декоративные SVG не принимают события мыши, не подменяют картографию и не загружают внешние ресурсы.
- Проверенный официальный пример сохраняет стоимость 95, остаток 5 и отображаемый Score 56,54.

Результаты объединённой проверки фиксируются отдельно после сборки всех трёх частей.
