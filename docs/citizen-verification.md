## Команды проверки

Node.js 24+; зависимости отсутствуют. На компьютере Данияра Node есть в `C:/Users/dania/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`, но отсутствует в системном PATH. Для тестов использован этот существующий runtime напрямую:

```powershell
& 'C:\Users\dania\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --test tests/*.test.js
```

Проверки домена охватывают сохранение после перезапуска, атомарность/конкурентные записи, повреждённый файл, недопустимые переходы, обязательную причину закрытия, ручные исправления, фильтры и защиту публичной проекции. HTTP-проверка проходит полный путь обращения, проверяет доступ администратора, ложный Origin/Host, подделку Telegram identity, неверный tracking token, фото и отсутствие утечки персональных данных. Отказ уведомления не откатывает сохранённое решение.

## Фактическая проверка 23.09.2026

- **100/100 автоматических тестов PASS**, включая 63 проверки прежнего приложения, 14 хранения, 17 Telegram и 6 HTTP обращений. Ни один тест не обращается к платной модели или настоящему боту.
- **Браузер PASS:** синтетическое обращение с районом/адресом/координатами → квитанция → панель → исправление приоритета/резюме/причины → назначение службы → решение → публичный трекинг с историей. Неверный код убирает старый результат и показывает отказ. Фильтр с пустым результатом показывает ноль, счётчики соответствуют выборке.
- **Мобильная ширина 390 px PASS:** обе страницы читаемы, поля и кнопки доступны. Console error/warn отсутствовали. Повторный запуск сохранил тестовое обращение.
- **Конкурентные правки:** UI хранит только изменённые поля и исходную версию. Сервер отклоняет устаревший PATCH с 409, не отменяет новое решение другого сотрудника. Во время сохранения поля заблокированы; старые GET не перезаписывают свежий результат. Ошибка доставки Telegram видна отдельно от успешного сохранения.
- **Карта:** синтетические координаты 51.13/71.42 проверены на реальной карте OpenStreetMap с маркером. Встроенный внешний iframe в этом браузере оставался пустым, поэтому финальный интерфейс использует обычную ссылку в отдельную вкладку без пустого блока. Адресный поиск не выдаётся за автоматическое геокодирование.
- **Живой Telegram:** задача «Подключи Trello Connector» настроила локальное окружение, server3001 и единственный polling. Пользователь подтвердил ответ на /start. Код и ключи другому участнику не передавались. Полный путь реального обращения через /send и уведомление о решении пока **NOT RUN**.
- **Живой анализ жалоб OpenAI: BLOCKED** — отсутствует ключ, решение пользователя по подключению ожидается. Локальные правила не засчитываются как выполненный LLM-анализ.

Основной экран параллельно упрощает задача «Запусти сайт для проверки», она же получила отдельное поручение пользователя объединить актуальную карту Азамата. Её изменения public/index.html, app.js, styles.css, comparison.js/css не входят в коммит модуля обращений. Карточки не следует переводить в СДЕЛАНО до интеграции и закрытия перечисленных ограничений.
