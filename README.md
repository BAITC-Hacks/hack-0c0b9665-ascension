# Аким на 5 часов · Ascension

Симулятор городских решений для кейса №12 HackAlem AI. Он помогает сравнить, **куда направить ограниченный бюджет и как выбранные инициативы повлияют на разные районы**. Пользователь выбирает пять мероприятий, получает расчёт качества жизни, видит слабейший район и сравнивает варианты при одинаковых расходах.

В основе — учебный набор пяти районов Астаны, 14 мероприятий и бюджет 100 условных единиц. Карта показывает реальную географию, а показатели и эффекты мероприятий взяты из синтетической модели кейса. Результат позволяет проверить логику решения; он не является прогнозом для реального города.

**[Открыть публичное демо](https://ascension-city-map.azamatbreach.workers.dev)** — для симулятора не нужны регистрация, личный API-ключ или подписка. Начните с кнопки **«Запустить демо»**.

| Что проверять | Где доступно |
| --- | --- |
| Выбор инициатив, бюджет, Score, карта, альтернативы одной меры, сравнение A/B и библиотека | Публичное демо или локальный запуск |
| Объяснение результата моделью | Публичное демо с серверным ключом, пока доступна общая квота; локально — по желанию владельца сервера |
| Обращение жителя → решение в панели акима → проверка статуса | Локальный Node.js-сервер: `/citizens.html` и `/mayor.html` |
| Telegram-приём обращений | Дополнительная настройка собственного бота; для проверки веб-сценария не требуется |

Модуль обращений использует отдельное хранилище Node.js. Его API не подключён к публичному Cloudflare Worker: наличие ссылки на страницу само по себе не означает доступность этого модуля в демо.

## Как запустить

Нужны **Node.js 24 или новее**, npm из его поставки и современный браузер. Для клонирования нужен Git; также можно скачать ZIP репозитория и открыть терминал в распакованной папке. Доступ к закрытому репозиторию выдаётся организаторами; самому приложению аккаунт не нужен.

```sh
git clone https://github.com/BAITC-Hacks/hack-0c0b9665-ascension.git
cd hack-0c0b9665-ascension
node --version
npm start
```

Откройте **[http://127.0.0.1:3000](http://127.0.0.1:3000)**. В текущей версии установка npm-пакетов и сборка для запуска не нужны: MapLibre уже включён в `public/vendor/`. Файл `.env.local` необязателен; сообщение о его отсутствии при первом запуске нормально. Остановка сервера — **Ctrl+C**.

Расчёты, сравнение сценариев и локальные обращения работают без ключей внешних сервисов. Для подложки карты и поиска нужен интернет, для 3D — поддержка WebGL. Если карта не загрузилась, расчёт и таблица показателей остаются доступны. Без ключа модели показывается **«Без AI · расчётное объяснение»**.

Если порт 3000 занят, создайте в корне `.env.local` со строкой `PORT=3001`, перезапустите сервер и откройте `http://127.0.0.1:3001`. Остальные необязательные настройки перечислены в [.env.example](.env.example). По умолчанию сервер слушает только `127.0.0.1`.

## Как проверить решение за 5 минут

### 1. Рассчитать официальный пример

На главной странице нажмите **«Запустить демо»**: план загрузится и рассчитается автоматически. В плане должны быть:

| Мера | Район |
| --- | --- |
| M7 — школа и детсад | Нура |
| M8 — центр семейного здоровья / поликлиника | Нура |
| M10 — освещение и камеры | Нура |
| M12 — единая цифровая платформа обращений | Весь город |
| M5 — перевод частного сектора на чистое топливо | Сарыарка |

Проверьте результат по таблице. Точка в точных значениях ниже — десятичный разделитель; интерфейс использует запятую и округляет до двух знаков.

| Показатель | До решений | Официальный пример A | Вариант B из следующего шага |
| --- | ---: | ---: | ---: |
| Общий Score | 52,56 | **56,54** | **55,30** |
| Изменение Score | — | +3,99 | +2,74 |
| Стоимость / остаток | 0 / 100 | **95 / 5** | **95 / 5** |
| Критических показателей | 2 | **0** | **1** |
| Оценка слабейшего района, Нуры | 49,18 | 52,96 | 51,86 |

Точные контрольные Score: `52.55768`, `56.54307`, `55.29777`. В блоке **«Дополнительный эффект сочетаний»** видно совместное действие M10 и M12 в Нуре.

### 2. Сравнить решение при том же бюджете

В блоке **«План изменений»** у школы и детсада поменяйте район **Нура → Есиль**, остальные решения оставьте прежними. Снова нажмите **«Рассчитать сценарий»**: получится вариант B из таблицы. Стоимость остаётся 95, но один показатель Нуры остаётся ниже критической границы.

Перейдите к разделу **«Сравнение сценариев»**. Сравнение показывает два последних расчёта; оценка Есиля меняется на **+1,10**, Нуры — на **−1,10**. **«Загрузить A»** возвращает решения первого варианта в форму — после загрузки выполните расчёт заново. **«Скачать сравнение (JSON)»** сохраняет снимки A/B для передачи и воспроизведения.

В **«Моих сценариях»** укажите название и нажмите **«Сохранить расчёт»**. План можно загрузить после перезагрузки страницы или импортировать из JSON сравнения. Библиотека хранит до 20 сценариев в этом браузере на этом адресе; сравнение двух последних расчётов — в памяти вкладки. Импортированные оценки не принимаются за результат сервера: загруженный план нужно пересчитать.

### 3. Найти альтернативу одной мере

Заново загрузите демо и рассчитайте его. В меню выберите **«Альтернативы решений»**, затем **«Найти альтернативы»**. Для официального примера поиск проверяет 181 замену, из которых 117 допустимы, и показывает пять вариантов с разными компромиссами между Score, слабейшим районом и расходами.

**«Загрузить вариант 1»** заменяет M5 в Сарыарке на M3 в Нуре. Нажмите **«Рассчитать сценарий»**: ожидаются стоимость **100**, остаток **0** и Score **57,21** (точно `57.20556`). Предварительный поиск выполняется в Web Worker на вашем устройстве по общему ядру; загруженный вариант заново проверяет сервер. Поиск охватывает замену одного решения и не обещает глобального оптимума. [Границы поиска](docs/policy-options.md).

### 4. Проверить ограничения

Заново загрузите официальный пример. Пока выбраны все пять мер, добавить шестую нельзя. Удалите **«Освещение и камеры»** (M10): останутся четыре меры стоимостью **83**. В направлении **«Транспорт»** попытайтесь добавить **«Умные светофоры»** (M2, стоимость 22). Набор на **105** не принимается, выбор остаётся **4 из 5**, кнопка расчёта недоступна. Сервер также отклоняет такой набор: `POST /api/simulate` возвращает HTTP **422** с ошибкой и без нового Score.

### 5. Проверить карту и объяснение

Верните официальный пример и выполните расчёт. Перейдите к разделу **«Карта и приоритеты»**, переключите показатель и состояние до/после, выберите район и режим 3D. При выборе другого города доступна география, а показатели Астаны скрываются: датасетов других городов в модели нет.

В блоке AI-анализа проверьте обозначение режима. Итог выбранного сценария вычисляется сервером; числа в панели альтернатив предварительно рассчитываются на устройстве. Доступная модель даёт AI-анализ; без ключа, при лимите или ошибке провайдера остаются рассчитанные числа и явно обозначенное расчётное объяснение. Отсутствие живого ответа модели не мешает повторить числовую проверку.

## Дополнительная проверка: обращения жителей

Выполняйте после локального `npm start`, используя вымышленные данные.

1. Откройте **[страницу жителя](http://127.0.0.1:3000/citizens.html)**. Введите, например: «Тестовое обращение: во дворе не работает освещение», укажите район и тестовый адрес. Подтвердите согласие формы и нажмите **«Отправить обращение»**. Геолокация не обязательна; фотографии предусмотрены в Telegram-пути.
2. Сохраните выданные **номер и личный код проверки**. Они нужны для просмотра статуса.
3. Откройте **[панель акима](http://127.0.0.1:3000/mayor.html)**. В стандартном локальном режиме токен не нужен. Найдите обращение, заполните **«Ответственный»**, установите статус **«В работе»** и нажмите **«Сохранить изменения»**. Затем выберите **«Решено»**, заполните **«Решение / результат»**, например «Тестовая проверка выполнена», и сохраните.
4. На странице жителя проверьте статус по номеру и коду: должны отображаться новое состояние и решение. Перезапустите сервер — отправленное обращение должно сохраниться.

Категория, приоритет и возможные повторы здесь определяются **локальными правилами**, которые сотрудник может исправить. AI симулятора не выполняет анализ обращений. Обращения не меняют исходные показатели районов.

Данные сохраняются в `var/complaints.json`, вне публичной статики и Git. Один файл обслуживает один процесс сервера; другой путь задаётся через `COMPLAINTS_FILE`. При удалённом доступе к панели требуется серверный `ADMIN_TOKEN`; без него разрешено только локальное демо. Подробности: [контракт обращений](docs/citizen-contract.md), [проверки модуля](docs/citizen-verification.md), [безопасность](docs/security.md).

Для дополнительного Telegram-пути задайте в `.env.local` `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и `TELEGRAM_WEBHOOK_SECRET`. При уже работающем `npm start` откройте второй терминал и выполните `npm run bot`. Если задаёте `BOT_SERVER_URL`, укажите адрес работающего сервера; в `.env.example` указан `http://127.0.0.1:3000`. В приватном чате бота: `/start` → новое обращение → согласие → описание → просмотр → отправка. Polling и webhook одновременно не запускаются. [Меню и команды бота](docs/telegram-ux.md).

## Технологии и устройство

| Компонент | Технология и назначение |
| --- | --- |
| Локальный сервер | Node.js 24+, встроенные HTTP и файловые API, JavaScript ES modules |
| Интерфейс | HTML, CSS, браузерный JavaScript; сравнение и сохранение сценариев в браузере |
| Расчёт | Общее детерминированное ядро `src/core/simulator.js` и фиксированный `data/city.json` |
| Поиск альтернатив | То же ядро в браузерном Web Worker; esbuild **0.28.2** только для пересборки |
| Карта | MapLibre GL JS **5.24.0**, OpenFreeMap / OpenStreetMap, поиск Photon |
| AI-объяснение | OpenAI Responses API, модель по умолчанию **`gpt-6-astra`**, строгий формат ответа |
| Публичный симулятор | Cloudflare Workers; постоянная общая квота AI в Durable Object |
| Обращения и бот | Node.js, JSON-хранилище, Telegram Bot API; отдельный модуль `src/complaints/` |
| Проверки | Встроенный `node:test`; проверка синтаксиса и границ модулей; GitHub Actions для Node 24 |

Путь расчёта: **браузер → HTTP API → проверка плана → расчёт по данным кейса → числовой результат → отдельное объяснение**. Node.js и Cloudflare Worker используют общий API-слой. Клиент не подменяет датасет или формулу; запрос объяснения также проходит повторный серверный расчёт. [Архитектура](docs/architecture.md), [контракт интеграции](docs/integration-contract.md), [развёртывание](docs/hosting.md).

## Формула и роль AI

Нужно выбрать ровно **пять уникальных мер**, не более двух из одного направления, общей стоимостью не выше 100. Для районной меры выбирается район. M1/M3 несовместимы в любом месте; M4/M7 и M5/M13 — в одном районе. Эффект меры учитывает задержку: `(8 − lag) / 8`; фиксированные синергии добавляются отдельно. Показатели ограничены диапазоном 0–100.

```text
Score = 0.7 × средняя оценка районов с весами населения
      + 0.3 × оценка самого слабого района
      − число значений «район × показатель» строго ниже 40
```

Оценка района — взвешенная сумма его показателей. Неиспользованный бюджет не даёт дополнительных баллов. [Официальные значения и правила в тестах](tests/simulator.acceptance.test.js).

Модель получает готовые факты и объясняет компромиссы. Числовая сводка и допустимые рекомендации формируются сервером; качественный текст модели всё равно следует сверять с таблицей. Модель не изменяет план и не назначает реальные поручения. [Граница доверия AI](docs/ai-grounding.md).

Для собственного AI-режима владелец сервера задаёт `OPENAI_API_KEY` и, при необходимости, `OPENAI_MODEL` в игнорируемом `.env.local`. В публичном демо ключ хранится в серверном секрете; посетитель его не вводит. Ожидание ответа ограничено 25 секундами. Общая квота публичного демо — 100 допусков к модели, до 10 в минуту и двух одновременно; ошибки провайдера также расходуют допуск. После исчерпания квоты работает расчётное пояснение.

Локальное объяснение может использовать проверенную замену одного решения. Это поиск среди соседних вариантов, без гарантии глобального оптимума. В серверном объяснении Cloudflare Worker такой перебор отключён; это явно указано в ответе. [Сохранённая проверка живого публичного AI от 23 сентября](docs/evidence/public-ai-smoke.json) относится к версии на момент проверки и не гарантирует наличие свободной квоты сейчас.

Публичная версия от **23 сентября, 16:14 GMT+5**: [`7ec1b3c`](https://github.com/BAITC-Hacks/hack-0c0b9665-ascension/commit/7ec1b3ca4e7a70d2d166ce9f2c553fe7a14c8ddc). Для неё подтверждены официальный результат, вариант `57.20556 / 100`, отказ для бюджета 105 и живой ответ `mode: ai`, `available: true`, `model: gpt-6-astra` по обновлённому контракту. Наличие ключа в `/api/health` само по себе не доказывает успешный вызов модели.

## Автоматическая проверка

В корне репозитория выполните:

```sh
npm test
node scripts/check-quality.js
```

Ожидаемый итог — все проверки проходят, команды завершаются с кодом 0. Тесты проверяют официальные числа, ограничения бюджета и совместимости, HTTP-контракты, безопасный импорт, fallback AI, обращения и Telegram. Внешние AI/Telegram-вызовы в автоматических проверках заменены подставными ответами: тесты не требуют ключей и не подтверждают доступность живых сервисов. Проверку пользовательского пути выполняйте по шагам выше.

Готовый браузерный Worker включён в репозиторий. **Только для его пересборки после изменения расчётного ядра или данных** установите dev-зависимости и выполните:

```sh
npm ci
npm run build:policy-worker
npm run check:policy-worker
```

Проверка сравнивает сборку с сохранённым файлом; для обычного `npm start` эти команды не нужны. [Сборка и интеграционные проверки](docs/browser-integration.md).

## Кабинеты команды и жителя

В объединённом UI сохранены восемь страниц: главная, `/citizens.html`, `/mayor.html`, `/desk.html`, `/akim.html`, `/resident.html`, `/results.html`, `/demo.html`. Все доступны через меню «Все разделы»; [состав общего выпуска и приёмка](docs/ui-release-handoff.md).

Для локального кабинета откройте `/akim.html`: сводка, проблемы, поручения, решения и совещание; доступны RU/KZ. Вход общий с `/desk.html`. Учётную запись руководителя создаёт `npm run desk:user -- akim akim`, исполнителя — `npm run desk:user -- executor operator`; повтор команды меняет пароль. [Кабинет акима](docs/akim-cabinet.md), [учётные записи и резервирование](docs/desk-operations.md).

Персональная страница `/resident.html` использует ссылку из карточки обращения; `/results.html` показывает отдельно опубликованные итоги, `/demo.html` — пошаговую демонстрацию. [Описание функций](docs/citizen-experience.md).

Эти кабинеты пока используют демонстрационные данные Node/SQLite и не отправляют ответы в Telegram. Реальный реестр `/citizens.html` и `/mayor.html` остаётся отдельным. Их объединение через согласованный Worker-адаптер описано в [контракте совместимости](docs/desk-complaints-contract.md). Наличие HTML на Worker не означает готовность API кабинетов. Публикацию выполняет Азамат после общей приёмки; этот PR не переключает Telegram и не выбирает между PR #25/#28.

Пять учебных районов не заявляются актуальным административным делением Астаны. Метки на карте — условные точки, а не официальные границы; наличие и высота 3D-зданий зависят от данных OSM. Другие города доступны для просмотра географии. Библиотека сценариев не синхронизируется между устройствами. Для применения в акимате потребуются реальные проверенные данные, калибровка эффектов, промышленное хранилище и управление доступом.
